# 🏎️ Turbo Race

**Turbo Race** é um jogo de corrida desenvolvido com HTML, CSS e JavaScript. O objetivo é controlar um carro, desviar dos veículos que aparecem na pista e conseguir a maior pontuação possível!

## 🎮 Sobre o jogo

O jogador controla um carro em uma estrada com três faixas. Durante a partida, precisa desviar dos obstáculos, evitar colisões e superar seu próprio recorde.

## ✨ Funcionalidades

- 🏁 Tela inicial com botão para começar.
- 🚗 Movimentação do carro.
- 🚙 Carros adversários como obstáculos.
- 💥 Sistema de colisão e fim de jogo.
- 🏆 Sistema de pontuação e recorde.
- ⚡ Aumento gradual da dificuldade.
- ⏸️ Opção para pausar e continuar.
- 🔄 Botão para reiniciar a partida.

## 🕹️ Como jogar

- **Seta para a esquerda (←):** mover o carro para a esquerda.
- **Seta para a direita (→):** mover o carro para a direita.
- **Barra de espaço:** pausar ou continuar o jogo.
- **Botões na tela:** movimentar o carro e controlar a partida.

O objetivo é desviar dos outros carros e acumular o máximo de pontos sem bater.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura do jogo.
- **CSS3:** estilo, cores e layout.
- **JavaScript:** lógica, movimentação, pontuação e colisões.
- **Canvas:** desenho da pista e dos veículos.
- **GitHub:** armazenamento e compartilhamento do código.

## ▶️ Como executar o jogo

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` com a extensão Live Server.
4. Clique em **JOGAR** e divirta-se!
